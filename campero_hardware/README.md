# campero_hardware

## 1) Overview

`campero_hardware` provides the live `ros2_control` hardware plugins for Campero mobile bases.

It specializes the generic mobile base hardware abstractions from `romea_mobile_base_hardware` and communicates with the Campero low-level interface through the Campero bridge.

The exported plugins are:

| Plugin | Mobile base architecture |
|---|---|
| `campero_hardware/CamperoHardware4WD` | `4WD` |
| `campero_hardware/CamperoHardware4WMD` | `4WMD` |

## 2) Hardware concept

The hardware plugin is loaded by `controller_manager` from the `<ros2_control>` description generated by `campero_description`.

From the controller point of view, it behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers` writes wheel commands to command interfaces, then reads feedback from state interfaces to compute odometry.

## 3) Relation with other packages

`campero_hardware` is the live hardware specialization of the Campero mobile base:

* `campero_description` selects the Campero hardware plugin in `live` mode;
* `romea_mobile_base_hardware` provides the reusable hardware abstractions;
* `campero_bridge` handles the communication with the embedded robot interface;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `campero_bringup` starts the controller manager and loads the selected hardware plugin in live mode.
